## What We Cover

| Category | Topics |
|--|--|
| **Prompt Engineering** | AIM framework, prompt patterns, cost-saving techniques |
| **AI Consumer Tools** | Image/audio/video AI, no-code automation, web scraping |
| **Python for AI** | Python basics, NumPy, Pandas, visualization libraries |
| **Local AI** | Ollama, LM Studio, GPU models, fine-tuning, TurboQuant |
| **AI Fundamentals** | LLM theory, ML concepts, transformer architecture |
| **Infrastructure** | Linux setup, Ubuntu/Zorin guides, dev environment tools |
| **Community** | Values, contributing guidelines, continuous learning |
