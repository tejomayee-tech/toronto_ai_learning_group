# 🎵 Linux Audio & Video Tools

## Music & Media Players

### Lollypop

**Purpose:** A lightweight and modern music player designed to work excellently on the GNOME desktop environment.

**Features:**

* **Intuitive Browsing:** Navigate through your collection by genre, artist, and album artwork.
* **Metadata Integration:** Automatically fetches lyrics, artist biographies, and high-quality cover art from online sources like Wikipedia and Last.fm.
* **Party Mode:** Features a mode that automatically selects party-related playlists for you.
* **Device Syncing:** Sync your music collection with Android phones and other MTP-compatible devices.

**Installation:**

```bash
# Ubuntu/Debian/Zorin
sudo add-apt-repository ppa:gnumdk/lollypop
sudo apt update && sudo apt install lollypop

# Fedora
sudo dnf install lollypop

# Arch Linux
sudo pacman -S lollypop

```

### VLC Media Player

**Purpose:** A versatile, open-source cross-platform multimedia player that plays almost any media format without needing extra codecs.

**Features:**

* **Universal Playback:** Plays virtually all audio and video formats, including MP3, MKV, MP4, FLAC, and even DVDs/VCDs.
* **Network Streaming:** Supports streaming protocols (HTTP, RTP, RTSP) and can act as a streaming server.
* **Advanced Tools:** Includes built-in tools for video conversion (transcoding), capturing screenshots, and recording your screen.

**Installation:**

```bash
# Ubuntu/Debian/Zorin
sudo apt update && sudo apt install vlc

# Fedora
sudo dnf install vlc

# Arch Linux
sudo pacman -S vlc

```
