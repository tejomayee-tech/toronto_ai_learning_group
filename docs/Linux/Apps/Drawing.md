# 🎨 Linux Image Editing & Illustration

Linux offers excellent tools for both professional photo manipulation and simple digital sketching. Below are the two most popular options for image editing and drawing.

## 1. GIMP (GNU Image Manipulation Program)

**GIMP** is the industry standard for open-source image editing. It is highly powerful and comparable to Adobe Photoshop.

* **Best For:** Photo retouching, complex composition, and professional graphic design.
* **Key Features:** Layers, masks, advanced filters, and customizable brushes.

### Installation

```bash
# Ubuntu/Debian
sudo apt update && sudo apt install gimp

```

---

## 2. Drawing

**Drawing** is a lightweight, easy-to-use application designed for the GNOME desktop. It is perfect for quick edits and simple illustrations.

* **Best For:** Simple sketches, adding text to screenshots, and basic cropping.
* **Key Features:** Intuitive interface, basic shapes (lines, circles, etc.), and a pencil tool.

### Installation

You can install **Drawing** via the standard package manager or as a Snap package:

**Via APT (Ubuntu/Debian):**

```bash
sudo apt update && sudo apt install drawing

```

**Via Snap (Universal):**

```bash
sudo snap install drawing

```

---

## 🚀 Which one should you use?

| Feature | GIMP | Drawing |
| --- | --- | --- |
| **Complexity** | High (Professional) | Low (Simple) |
| **Layers** | Yes | Limited |
| **Startup Speed** | Slower | Instant |
| **Recommended Use** | Editing photos | Quick annotations |
