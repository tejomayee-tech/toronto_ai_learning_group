GIMP is one of best tools for image editing and can used for drawing as well.

To install **Drawing** on Ubuntu, you can use the following command in your terminal:

```bash
sudo apt-get update && sudo apt-get install drawing
```

Alternatively, you can install it via Snap if you have Snapd installed:

```bash
sudo snap install drawing
```

Once installed, you can find it in your applications menu. Let me know how it goes or if you need help with anything else!
